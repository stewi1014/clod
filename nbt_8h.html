Detailed Description

Aims to make it straightforward to operate on serialised NBT data, but does not offer any intermediate representation of NBT data.

Methods operate directly on the serialised data, which makes it fast as all get-out for parsing and making changes to serialised data. However, some use cases do not need changes to be serialised, and can benefit from storing changes in an intermediate data format - this library is not for those use cases.

This approach also comes with an ergonomic downside; Nuances of the NBT format are not abstracted away by this library, and using it can be verbose. So, if you're going to use it, make sure you're aware of how the NBT format works.
